# 识别后确认关卡 — 本轮范围

这是对上一版 v2 的工作稿补充。上传只请求 `recognize, clues`；后端默认也是这两步。
前端显示识别商品和可选销售证据，用户确认后才运行场景、商品、经营总结、扩写、检索和复核。
刷新不会自动继续；确认有持久版本；修改商品范围或再次识别会使旧确认失效。

本轮确认界面支持原有商品纳入/排除及销售证据查看。
**销售数字、识别名称的逐项在线修正和补商品编辑器尚未在本轮实现**，不能声称已覆盖。

所有代码在对话工作环境，未推送 GitHub、未修改用户电脑、未部署。
本包继承 v2 的原文件校验和 RAG 策略；不会改变检索模型、权重、阈值或数量。
