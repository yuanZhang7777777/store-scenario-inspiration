# METIS：首页与店铺工作页

状态：2026-09-22，已接入 UI 工作区的 React / FastAPI 应用。当前实现以本文和源码为准。[早期原型](2026-09-22-export-first-prototype.html) 已冻结，不再同步本轮新增交互；工作区位置见 [UI 基准](2026-09-22-ui-baseline.md)。

## 页面与操作

只保留两种界面：

- 首页 `/`：新建店铺入口、历史店铺列表。列表显示名称、国家、截图数及可核实状态，每 5 秒更新；点击记录进入该店工作页。
- 店铺工作页：新建输入 `/stores/new`，提交后进入 `/stores/:id`。选择国家、上传截图或填写商品名 → **开始生成** → **导出 Excel**。没有独立等待页、结果页或中途确认站。

国家必须显式选择，店名选填。上传沿用数量、大小、格式和重复校验；支持粘贴、拖入、缩略图删除和放大。生成设置复用后端 schema，不另存一份默认规则。创建成功但启动失败时保留 ID，继续生成不重复建店。

当前会话内返回首页或查看历史会保留未提交的截图、商品和设置；完整提交成功后清空截图和商品。刷新页面不能恢复未提交的 File 对象。返回首页不会停止后台任务；重新打开历史店铺只读已有结果，不自动调用模型。

## 工作页布局

由上往下：店铺标题与更新入口 → **紧凑进度** → 店铺分析 → 场景与商品 → **导出 Excel**。

- 店铺截图、商品资料和生成设置可以展开修改；不挤占长报告的主要空间。
- 完整分析默认展开，顺序为执行结论、店铺画像、当前产品结构、目标人群、场景方向、未来产品结构、运营策略。保留经营判断，不渲染依据和边界声明，原数据字段仍保留。
- 右侧固定章节导航可定位各章、场景商品和页尾导出；窄屏改为横向导航。导航只滚动，不触发下载。轮询不自动滚动、切页或折叠正在阅读的内容。
- 场景与商品采用场景 → 商品类型 → 主 SKU 三级结构。场景和商品类型默认折叠；只有实际展开的类型才渲染 SKU 行，避免数千条商品挤进页面。
- 导出区在内容之后，范围、去重配置、文件内容和数量全部可见，不放进折叠面板。

使用原有蓝色、白色与深色文字；不增加图标库或动效依赖。只有进行中的进度节点和分析占位有轻微流动，完成或停止后停止；系统设置减少动态效果时停用动画和顺滑滚动。

## 进度和术语

首次“开始生成”不传阶段清单，后端一次运行全部八步。每 2 秒轮询真实任务；请求未返回时不叠加新的轮询，产物拉取成功后才记为已显示。

| 用户看到的节点 | 后端步骤 |
|---|---|
| 店铺分析 | recognize → clues → synthesis |
| 生成场景 | scenes |
| 场景商品 | products |
| 匹配商品 | expand → retrieval → rerank |

进度展示当前节点、完成状态和已用时间，不编造百分比或剩余时间。**不再显示“处理详情”**。分析生成后立即可读，商品匹配继续；错误提示、停止和继续生成仍保留。

需要更新时把 `outdated` 与未完成阶段合并，按原有顺序继续；成功步骤不因为页面重开而重跑。修改参数不会自动启动任务；按“应用设置并更新”才执行。

## 勾选与导出

新店默认选中全部场景和保留的候选商品。取消场景或商品类型会覆盖之后到达的候选，轮询不重新勾上。部分选择显示中间态；保留全选、取消全选、类型内反选和 SKU“以上全选”。被后端剔除的商品不重新纳入可选清单。

勾选按店铺保存在当前浏览器 `ssi.selection.v2.<storeId>`；旧 `ssi.picked` 的选择会迁移，包含之前已清空的选择，不强制覆盖。展开状态只在当前工作页停留期间保留。

导出只有一套勾选集合，避免“自选范围”与场景复选框互相覆盖：

- **全部已选商品**：默认。未调整时即全部场景的保留候选；手动勾选后即自选清单。
- **仅目标国家有货**：在当前已选集合内过滤；不会恢复已取消的场景。库存未知不算有货，库存不可用时禁用此范围。
- **附带去重商品清单**：默认开启。保留原场景报告，并追加每主 SKU 一行的汇总表。

页面分别显示导出场景数、跨场景去重后的主 SKU 数，以及每场景去重数量。列表中的“只看有货 / 已选”只改变显示，不改变导出范围。导出前再次核对后端就绪状态，重复点击只提交一次。

文件沿用原有主 SKU 三列布局，实际工作表为主 SKU 清单、子 SKU 清单、店铺概况、可选去重商品清单、口径说明。**候选明细仍未实施**，界面不声称已有该表；本轮未改变 Excel 布局和数据契约。

## 接口与异常

继续使用现有接口，新增的只是元数据和导出保护：

| 接口 | 当前行为 |
|---|---|
| `GET /api/stores` | 增加 `job_status`、`needs_update`，不返回整个任务日志 |
| `GET /api/stores/{id}` | 增加 `export_blocked_reason`，空字符串表示就绪；缺子款明细时 `outdated` 加入 retrieval / rerank |
| `POST /api/stores/{id}/adoption/export` | 沿用 picks / dedupe；生成文件期间持有原有店铺锁，拒绝与任务写入并发；过期结果返回 409 |

上传或启动失败保留输入；轮询断连继续重试，保留已显示内容；任务失败或停止保留成功部分，用“继续生成”补足剩余阶段。过期结果会标示，生成中、未保存的设置有修改、缺子款快照、结果过期或范围为空时禁用导出。

只检查 `stock_children.json` 是否存在，不把“库存不可用”误判成“文件缺失”：库存未核验的结果仍可导出全部已选商品。版本检查沿用已有依赖与参数记录；没有历史运行记录的命令行产物仍按后端原规则判断，不新增不可证实的历史参数承诺。
